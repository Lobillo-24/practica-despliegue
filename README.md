# Calculadora

Calculadora básica con suma, resta y división. Incluye un workflow que comprueba el programa y genera su documentación a partir de los comentarios.

## Requisitos
- Node.js 22 y npm

## Instalación
    git clone git@github.com:Lobillo-24/practica-despliegue.git
    cd practica-despliegue
    npm install

## Uso
- `npm test` → pasa los tests
- `npm run docs` → genera la documentación en `docs/`

## Documentación
Generada con JSDoc. En GitHub: Actions → última ejecución → Artifacts → documentacion.
